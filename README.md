# KarlTech IT Support — Zendesk Help Desk Project

## Overview

This project documents my hands-on exploration of Zendesk, an industry-standard IT help desk and ticketing platform used widely in enterprise IT support environments. The goal was to get familiar with how real help desk operations are structured — from account configuration to ticket lifecycle management — and to understand the workflows that Tier 1 IT support professionals use daily.

## Key Concepts Demonstrated

- **Ticket lifecycle management** — Moving tickets through Open, Pending, and Solved states
- **Agent assignment and triage** — Assigning tickets based on issue type and priority
- **Internal documentation** — Using internal notes to log troubleshooting steps as a real technician would
- **Priority classification** — Distinguishing between High, Normal, and Low priority issues
- **Help desk workflow** — Understanding how IT tickets are created, tracked, escalated, and resolved

---

## Real-World Application

Ticketing systems like Zendesk, ServiceNow, and Jira Service Management are standard tools in IT support environments. The workflows practiced here — triage, assignment, status management, and internal documentation — directly mirror what Tier 1 and Tier 2 help desk professionals do daily. Familiarity with these systems reduces ramp-up time in any IT support role.
